{{- /* Floating subject bubbles. Input: a slice of dicts with "title", "url", "count". Renders each as a round link whose size follows the count (square root, so a subject with four times the notes gets a bubble twice as wide). A small script packs the circles into the container without overlaps and lets them drift; without JavaScript they fall back to a wrapped row of circles. Colors come from a fixed pastel palette (assets/css/custom.css, --bub-*), assigned per subject by a stable hash of its name so a subject keeps its color when others are added. Styles live in custom.css under ".bubbles". */ -}} {{- $palette := 9 -}} {{- $max := 1 -}} {{- range . }}{{ if gt .count $max }}{{ $max = .count }}{{ end }}{{ end -}}
{{- range $i, $b := sort . "title" }} {{- $slot := mod $i $palette -}} {{ $b.title }} {{ $b.count }} {{- end }}
