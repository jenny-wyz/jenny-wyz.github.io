This is a sample journal entry. Replace it, or keep it as the first page of the record.

A journal entry is just a Markdown file in `content/journal/`. The file name can be anything; starting it with the date keeps the folder sorted. The part between the `---` lines (the front matter) holds the title, date, an optional summary and tags.

Entries can mix languages freely. Zum Beispiel ein Satz auf Deutsch. 或者一句中文。 The site treats it all as plain text.
